## Stattic - Decentralized Publishing

Stattic is a [static site generator](https://stattic.site) built with Python, Tailwind CSS, and Jinja2 templates. You can build your own [themes](https://themes.stattic.site), import content from WordPress® with [autoStattic](https://github.com/getstattic/autoStattic), and soon will be able to use our custom CMS solution, Stattic Admin.
